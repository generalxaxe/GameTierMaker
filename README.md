# Game TierMaker

Бесплатная программа для Windows, в которой можно собирать **тир-листы по играм**: находишь игру через поиск, она появляется карточкой с обложкой, и ты перетаскиваешь её в нужный тир — от **S** до **F**.

Программа сделана именно под игры: поиск идёт по игровым каталогам (Steam, GOG, VNDB, Wikipedia), а не по произвольным картинкам. Если игры нигде нет — можно добавить её со своей обложкой.

> *English: a free Windows app for building video game tier lists. Search a game, get a cover card, drag it into S–F tiers, export as PNG. No account, no installer, everything is stored locally.*

## Как это работает

1. **Создай тир-лист** — кнопка «Новый тир-лист» слева. Листы можно раскладывать по папкам.
2. **Найди игру** — начни печатать название в строке поиска сверху. Понимает и русские сокращения: «дота», «ведьмак 3», «гта 5», «кс».
3. **Выбери игру из списка** — она скачает обложку и появится карточкой в нижней панели «Без тира».
4. **Перетащи карточку в тир** — S, A, B, C, D, E или F. Порядок внутри тира тоже меняется перетаскиванием.
5. **Сохрани результат** — кнопка «Экспорт» сохраняет тир-лист картинкой PNG или копирует её в буфер обмена, чтобы сразу вставить в чат.

Сохранять вручную ничего не нужно: каждое действие записывается автоматически.

### Что ещё умеет

- **Отмена** последних действий (до 50 шагов) — перемещение, удаление, сброс.
- **Своя картинка** — добавить игру с обложкой с компьютера, если её нет в каталогах.
- **Меню по правой кнопке** на карточке — отправить в любой тир, убрать вниз, удалить.
- **Меню по правой кнопке** на тир-листе — переименовать, дублировать, перенести в другую папку, удалить.
- **Счётчики** игр в каждом тире.

### Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Ctrl+F` | перейти в поиск |
| `↑` `↓` `Enter` | выбрать игру в результатах поиска |
| `Esc` | закрыть результаты / очистить поиск |
| `Ctrl+Z` | отменить последнее действие |
| `Ctrl+E` | сохранить тир-лист как PNG |
| `Ctrl+Shift+C` | скопировать тир-лист картинкой в буфер |
| `F2` | переименовать выбранный тир-лист или папку |
| `Del` | удалить выбранный тир-лист или папку |

## Откуда берётся информация

Названия игр и обложки программа получает из открытых источников в момент поиска. Каждый результат помечен значком источника.

| Значок | Источник | Что там ищется |
|---|---|---|
| **STEAM** | поиск магазина Steam (`store.steampowered.com`) | игры из каталога Steam |
| **GOG** | каталог GOG (`catalog.gog.com`) | игры из магазина GOG |
| **VNDB 18+** | база визуальных новелл VNDB (`api.vndb.org`) | визуальные новеллы, в том числе для взрослых |
| **GLOBAL** | Wikipedia (`en.wikipedia.org`) и небольшой встроенный список | игры, которых нет в Steam: Minecraft, Roblox, Valorant, League of Legends, консольные эксклюзивы и т. п. |

Источник **VNDB** может показывать контент 18+ — это база визуальных новелл, и в ней есть игры для взрослых.

Программа не связана со Steam, Valve, GOG, VNDB и Wikipedia. Обложки и названия принадлежат их правообладателям и загружаются только на твой компьютер для личного использования.

## Где хранятся данные и что уходит в интернет

- **Всё хранится локально.** Рядом с exe создаётся папка `tiermaker_data`: в ней файл с тир-листами (`workspace.json`) и скачанные обложки (`images`).
- **Нет аккаунтов, регистрации, рекламы и сбора статистики.**
- **В интернет уходит только текст поискового запроса** — в четыре сервиса из таблицы выше, чтобы найти игру и скачать её обложку. Сами тир-листы никуда не отправляются.
- **Без интернета** программа открывается и работает с уже добавленными играми; не будет работать только поиск новых.
- **Резервные копии** тир-листов делаются автоматически при каждом запуске — в `tiermaker_data\backups` (хранятся последние 30).

Чтобы перенести свои тир-листы на другой компьютер, скопируй exe вместе с папкой `tiermaker_data`.

## Сборка из исходников

Нужен Python 3.11 или новее.

```bash
pip install -r requirements.txt
```

Запуск без сборки:

```bash
python main.py
```

Сборка exe (результат появится в папке `dist`):

```bash
pip install pyinstaller
```

```bash
pyinstaller --noconfirm GameTierMaker.spec
```

Программа написана на Python с интерфейсом на PyQt6; для поиска используется `requests`, для обработки обложек — Pillow.
